# kex2018 — Bachelor's Thesis in Computer Science

**A performance survey of coverage algorithms for simple robotic vacuum cleaners**

KTH Royal Institute of Technology, 2018.

Evaluates coverage path planning algorithms (random walk, spiral, boustrophedon, wall follow) for simple robotic vacuum cleaners through simulation.

## Contents

- `draft.tex` / `draft.pdf` — Thesis document
- `seminardraft.tex` / `seminardraft.pdf` — Seminar draft
- `src/` — Simulation code (Python with bmp-based room maps)
- `img/` — Result charts and screenshots
- `ref/` — Reference papers
- `review/` — Review documentation
- `kththesis.cls` — KTH thesis LaTeX class
